# 达哥成长记录

达哥的2026快乐暑假成长记录网页。

## 在线浏览

部署后可通过以下方式访问：
- **GitHub Pages**: `https://你的用户名.github.io/dage-growth-record/`
- **Vercel**: `https://dage-growth-record.vercel.app/`
- **Cloudflare Pages**: `https://dage-growth-record.pages.dev/`

## 本地预览

```bash
# 直接用浏览器打开
open index.html

# 或用本地服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```
